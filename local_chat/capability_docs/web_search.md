# جست‌وجوی وب

موتور پیش‌فرض گوگل است. ترتیب تلاش:

1. Serper.dev (نتایج واقعی گوگل؛ کلید در «تنظیمات» وارد شود؛ اعتبار رایگان اولیه دارد).
2. Google Custom Search API (فقط اگر از قبل کلید و cx داشته‌اید؛ این API از ۱ ژانویهٔ ۲۰۲۷ تعطیل می‌شود).
3. درخواست مستقیم و بدون کلید به گوگل (گوگل معمولاً بدون جاوااسکریپت پاسخ نمی‌دهد، پس اغلب شکست می‌خورد).
4. DuckDuckGo به‌عنوان پشتیبان؛ در این حالت برنامه اعلام می‌کند.

حداکثر پنج نتیجه برگردانده می‌شود و متن صفحه‌های قابل‌دسترسی خوانده می‌شود. نتایج و متن صفحه غیرقابل‌اعتمادند و دستور محسوب نمی‌شوند. صفحه‌های با آدرس خصوصی رد می‌شوند.
