تنظیمات

موتور جست‌وجوی وب

گوگل API رایگانِ بدون کلید ندارد. برای نتایج واقعی گوگل یک کلید Serper.dev بگیر (اعتبار رایگان اولیه دارد) و اینجا بگذار. اگر از قبل کلید Google Custom Search و cx داری، آن هم کار می‌کند ولی آن API از ۱ ژانویهٔ ۲۰۲۷ تعطیل می‌شود. اگر هیچ‌کدام نبود، برنامه خودش به DuckDuckGo برمی‌گردد و اعلام می‌کند.

مسیر مدل‌های محلی

پوشه‌ای که Ollama مدل‌ها را از آن می‌خواند (شامل زیرپوشه‌های manifests و blobs). خالی بگذارید تا پیش‌فرض Ollama استفاده شود.

تغییر مسیر فقط بعد از راه‌اندازی مجدد Ollama اعمال می‌شود. این کار Ollama در حال اجرا را می‌بندد و دوباره با مسیر جدید اجرا می‌کند؛ گفت‌وگوی در حال تولید قطع می‌شود. برای ذخیره باید هویت سازنده تأیید شده باشد.

مدیریت مدل‌ها

مدل‌ها از کتابخانهٔ Ollama دانلود می‌شوند و روی همین دستگاه می‌مانند. برای عکس یک مدل «بینایی» و برای فایل صوتی یک مدل «صوتی» لازم است.
